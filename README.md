# Delta Battle (Forge 1.20.1)

Мультиплеерные битвы в стиле Deltarune. Бой считает сервер, у каждого игрока своё сердце в общей коробке.
**Любую битву (монстры, боссы, несколько врагов) можно описать JSON-файлом, без кода.**

## Сборка
Файлы проекта лежат в КОРНЕ репозитория. Залей на GitHub -> вкладка Actions -> `build` -> Artifacts -> jar в `mods/`.
Мод нужен и на клиенте, и на сервере; нужен GeckoLib 4.4+ (Forge 1.20.1). JDK 17.

## Игра
- Пати: `/dparty invite <ник>`, `/dparty accept|decline|leave|list` (до 4 игроков).
- Фроггит: яйцо призыва или болота. Контакт / ПКМ / удар запускает бой для пати.
- Управление: стрелки/WASD, Z/Enter - выбрать, X - назад (в атаке - медленнее сердце).
- Команды (OP):
  - `/deltabattle start <битва> [игроки]` - бой без моба
  - `/deltabattle summon <битва> [x y z]` - моб в мире, начинает эту битву при контакте
  - `/deltabattle list` - загруженные битвы

## Внешний вид (Deltarune)
Экран 640x480 как в оригинале: слева спрайты пати и вертикальный TP-бар, справа враги, снизу панели героев с иконками
FIGHT / ACT / ITEM / SPARE / DEFEND (активный герой выдвигается вперёд), текстовое поле с `*`, в атаке по центру
зелёная рамка с красным сердцем. Враги выбираются в списке с HP и MERCY. Герои: 3D-модели GeckoLib или встроенные силуэты (скины игроков не используются).
Шрифт: положи `deltarune.ttf` (например 8bitoperator или Determination Mono, по их лицензиям) в
`src/main/resources/assets/deltabattle/font/` - мод подхватит его сам (без файла используется шрифт Minecraft).
Спрайты врагов - png (в моде заглушки), размеры width/height в JSON задаются в единицах 320x240 (на экране x2).

## Персонажи: модели Blockbench / GeckoLib
Мод требует **GeckoLib 4.4+ для Forge 1.20.1** (в папку mods). Враги, герои и NPC в мире могут быть 3D-моделями:
1. В Blockbench сделайте модель (формат GeckoLib) и анимации; экспортируйте `имя.geo.json`, `имя.animation.json` и текстуру `имя.png`.
2. Откройте редактор и **перетащите эти файлы прямо в окно игры**. Они копируются в папку игры `deltabattle_assets` (подключается
   сама как ресурс-пак), ресурсы перезагружаются, и файлы появляются в выпадающих списках (кнопка `v`). `.ogg` тоже можно
   перетащить: он становится музыкой `deltabattle:music.<имя>`.
3. Враг -> **Модель 3D**: выберите geo, файл анимаций, текстуру; затем анимации для состояний (покой, атака, удар по нему, речь, поражение, пощада).
   Размер, сдвиг и поворот правятся тут же, результат виден в 3D-вьюпорте (мышью можно вращать, колесом масштабировать, кнопки внизу проигрывают анимации).
4. Герои: ветка **Герои (модели)** у битвы; элемент №1 = первый игрок в пати. Если модели нет, рисуется встроенный силуэт.
5. Моб в мире (`Моб в мир` / `/deltabattle summon`) использует модель первого врага. Его анимации покоя и ходьбы берутся из `anim_idle` / `anim_walk`.
Файлы моделей клиентские: чтобы их видели другие игроки, им нужна та же папка `deltabattle_assets` (или ресурс-пак с теми же файлами).

## Редактор битв в игре (креатив)
Открыть: предмет **«Редактор битв»** (ПКМ) или `/deltabattle edit [битва]`. Нужен креатив (или OP).
- **Слева дерево битвы:** Враги -> враг -> Модель 3D / Атаки / Стадии / Действия / Реплики; Герои (модели); Триггеры текста и музыки; Заклинания и т.д.
  Жёлтые строки - списки, `+` справа добавляет элемент. Стрелка раскрывает ветку.
- **Справа свойства** выбранного. Поля с кнопкой `v` открывают список вариантов (файлы моделей, анимации, музыка, типы паттернов).
  У элемента списка кнопки Копия / Вверх / Вниз / Удалить. Подсказка по полю - внизу при наведении.
- **В центре вьюпорт.** Модель: 3D-превью с анимациями. Атака: живое превью + **таймлайн** (метки появления пуль, красная линия = конец, бирюзовая = реплика),
  клик/тяни по таймлайну = перемотка, `||` = пауза, клик по рамке = переставить сердце (цель для `aimed`).
- **Стадии босса:** `Стадии` у врага. Включаются по HP (%) и/или с хода N, подменяют атаки/реплики, могут сменить музыку.
- **Текст в нужный момент:** `Текст и музыка по триггерам` (start, turn, hp_below, enemy_killed, enemy_spared, player_down): текст, реплика-пузырь, музыка, звук.
  Реплика посреди атаки - поля `Реплика в атаке` и `Тик реплики` у самой атаки.
- **Музыка:** поле `Музыка` у битвы, стадии или триггера (`stop` = тишина). Ванильные звуки тоже подходят.
- Кнопки сверху: **Сохранить** (в папку мира `deltabattle/encounters`, действует сразу), **Тест боя**, **Тест атаки** (бой только с этой атакой),
  **Моб в мир**, **Список**. После теста вы возвращаетесь в редактор. Закрытие сохраняет изменения.
- Файл битвы можно скопировать в `data/<ns>/encounters/` мода или датапака.

## Отмена боя
В бою клавиша **DELETE** (креатив или OP) отменяет бой для всех участников, без наград. Команды: `/deltabattle abort [игроки]`, `/deltabattle abortall`.

## Как сделать свою битву
Файл `data/<namespace>/encounters/<имя>.json` (в моде: `src/main/resources/data/deltabattle/encounters/`, или в
обычном датапаке мира; перечитывается `/reload`). Примеры: `froggit`, `jeep`, `duo` (2 врага), `knight_boss` (босс с фазами).
Тексты - обычная строка или ключ из lang. В тексте: `%1$s` - имя игрока, `%2$s` - имя врага. Ведущую `*` не писать.

Корень: `intro, win_text, spare_text, lose_text, party_hp, player_atk, exp, gold, bg, grid (#RRGGBB), world_texture,
world_scale, world_behavior (hop|still), enemies[1..3], spells[], items[], reward_items[], win_commands[], spare_commands[], lose_commands[]`

Враг: `name, hp, atk, def, texture, tex_w, tex_h, width, height, color, bob, squash, flavor[], flavor_spareable, flavor_low,
acts[], dialogue[], attack_mode (random|sequence), attacks[], phases[]`

- act: `name, text, reply (реплика врага), mercy (100 = можно пощадить), damage, heal, tp_cost`
- spell (ACT-меню, общие): `name, text, tp_cost, type (heal_party|damage|mercy), power, slot (-1 все, 0..3 только этот игрок)`
- phase (босс): `hp_pct, notice, attacks, dialogue, flavor` - когда HP% <= hp_pct, подменяют поля врага.
- attack: `pattern, texture, w, h, radius, count (1-32), speed, interval, start, delay, duration, damage (0 = atk врага), weight,
  box_w, box_h, from (top|bottom|left|right|random), wobble, waves, gap, angle_step, hover`
  - patterns: `aimed` (зависают и летят в душу), `rain`, `sweep`, `ring` (с проходом), `spiral`, `hop` (прыжки по дну), `bounce`
- reward_items: `{"item":"minecraft:diamond","count":2}`; commands выполняются от каждого участника с правами 4 (`give @s ...`).

Текстуры: `assets/<ns>/textures/gui/*.png`, в JSON `"texture": "deltabattle:textures/gui/jeep.png"`.
Несколько врагов: выбор цели для FIGHT / ACT / SPARE; бой кончается, когда все убиты или пощажены.

## Технически
- Позиции пуль - чистая функция (параметры, seed, время), по сети не передаются.
- Сервер шлёт клиенту JSON битвы в пакете START, поэтому датапак нужен только на сервере.

## Что можно сделать дальше
Музыка/звуки на битву, шрифт Determination, анимации спрайтов героев, фоны по биомам, предметы с выбором в меню,
катсцены, привязка битвы к существующим мобам по тегу.
